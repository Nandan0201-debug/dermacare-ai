# DermaCare AI

AI-powered skin and wound triage web application built using React, FastAPI, CLIP, and Groq LLM.

## Features

- AI-based skin and wound image analysis
- Medical-style triage report generation
- PDF report download
- AI chatbot for follow-up guidance
- Responsive modern UI
- Risk-level detection and condition prediction

## Tech Stack

### Frontend
- React.js
- Vite
- CSS3
- Lucide React
- jsPDF

### Backend
- FastAPI
- Python
- CLIP Model
- Transformers
- Torch
- Groq API

## Project Workflow

1. Upload wound or skin image
2. AI analyzes image using CLIP
3. System generates condition prediction
4. Medical triage report is created
5. PDF report can be downloaded
6. Chatbot provides safe follow-up guidance
